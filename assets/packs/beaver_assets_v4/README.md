# 꼬리원정대 에셋팩 v4

요청서 v4의 보정·F1~F6·G를 위한 추가 팩. 그래픽 131 ID, 1069 PNG 프레임, 오디오 17개. 기존 v1~v3 전체를 포함한 합본이 아니다.

1. `docs/INTEGRATION.md`를 개발 AI에게 먼저 읽힌다.
2. 기존 `tools/import_asset_pack.gd`로 이 팩의 `manifest.json`을 읽고 **ID+애니메이션 키 단위**로 병합한다.
3. 오디오는 별도의 `audio_manifest.json`으로 등록한다.
4. 압축을 푼 뒤 `preview.html`을 열면 동작·정지 상태·오디오를 확인할 수 있다. 이 파일은 에셋 확인용이며 게임 클라이언트가 아니다.

`assets/`가 게임용 PNG다. 편집용 생성 원본 `source_sheets/`는 별도 `beaver_assets_v4_sources.zip`에 있다. 두 압축을 같은 상위 폴더에 풀면 한 팩으로 합쳐진다. 개발에는 기본 ZIP만 있어도 된다. 시트의 셀 크기가 게임용 규격과 같지는 않다. 게임에는 개별 PNG를 사용한다. `QA_REPORT.md`에서 파일 검사와 실제 엔진 검수의 범위를 구분한다.

그림은 AI로 새로 제작하고 규격에 맞게 분리·정렬했다. 오디오는 외부 샘플 없이 합성한 독자적인 효과음·음악·환경음이며 실제 악기 연주나 자연 녹음이 아니다. 최종 믹싱은 게임 안에서 조정한다.
