그래픽 131 ID, 상태·방향 및 변형 선택 353개, 새 생성 원본 177장. 게임용 PNG에는 기존 버들강 직선 물가 4장이 포함된다. WAV 효과음 12개와 OGG 음악·환경음 5개를 제공한다. 기존 v1~v3 전체 합본은 아니다.

## 통과한 검사

- 모든 요청 작업 177개가 색인에 존재하며 누락이 없다. 등록 경로 1,069개는 서로 다르다.
- 게임용 프레임 전체의 디코딩, 지정 크기, RGBA, 빈 프레임, 투명 배경, 타일 불투명도를 검사했다. 동일 바이트 파일 중복은 없다.
- 접점 인덱스와 프레임 라벨 길이가 프레임 수와 맞는다. 정지 변형은 select_frame이며 자동 반복하지 않는다.
- 편집 원본과 미리보기 PNG도 디코딩했다. GIF의 모든 프레임을 디코딩했다.
- 두 카드의 문서상 content_rect 전체가 alpha=0이다. 캔버스는 256×352 / 256×160이다.
- 오디오 17개를 디코딩하고 채널·44.1kHz·길이를 확인했다. 디코딩 후 피크는 1.0 미만이며 루프 경계의 샘플 변화량도 검사했다. 경계 검사는 청취·최종 믹싱을 대신하지 않는다.
- preview.html의 JavaScript 문법을 검사했다. 실제 브라우저 실행은 검증하지 않았다.

## 제작 중 수정한 항목

톱니전사의 붉은 의상과 무기, 두꺼비 탈피와 나방 사망의 일부 방향, 기어게 사망 방향 순서, 독립 닻·지지목·밧줄·톱니·목재 소품을 보정했다. 뿌리댐 바닥은 물이 섞이지 않는 나무판 재질로 다시 만들었다. 뿌리댐 물 타일은 생성 그림의 물 부분을 잘라 사용했다. 물가 코너는 NW·NE·SE·SW 순으로 대조했다. 전투·보스 음악의 타악기 시작점을 완만하게 처리했다.

## 개발 클라이언트에서 확인할 항목

프로젝트 코드·실행 파일을 받지 않아 Godot 임포터, 렌더링, 서버 동기화, 실제 플레이는 시험하지 않았다. 기존 idle과 새 동작 간 체형·발 위치·재생 속도, 겹치는 VFX, 타일 연결 이음새와 인덱스 해석, 긴 한글 설명의 줄바꿈, 4인 동시 효과음의 음량을 확인해야 한다. 직업별 피해·치유 밸런스나 보스 기믹 난이도 검증은 이번 에셋 작업에 포함되지 않는다.

원본은 AI 생성 시트다. 방향별 그림을 분리했으며 좌우를 코드로 뒤집어 만든 프레임은 없다. 시트별 구도와 크기가 달라 정렬·리사이즈를 거쳤다. 512 프레임이라는 표기는 출력 캔버스 크기이며 모든 원본 셀이 512px 이상인 것은 아니다. 개별 동작의 세부 형태 일관성은 실제 재생 상태에서 추가로 다듬을 수 있다.

v3 카드에는 content_rect가 없고 중앙이 불투명한 그림이었다. ui_layout.json에 안전한 설명 영역 기준을 새로 명시하고 그 기준에서 상하 16px를 확장했다. 기존 클라이언트의 텍스트 영역과 정확히 같은 값이었다고 가정하지 않는다.

오디오는 외부 녹음 없이 직접 합성했다. 음악은 32마디 안에서 선율·밀도·리듬을 바꾸며 순환하고, 환경음은 주기성을 갖도록 합성했다. 실제 악기 녹음·자연 녹음은 아니다.
