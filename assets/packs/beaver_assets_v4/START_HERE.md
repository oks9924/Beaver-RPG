# 개발 AI에게 함께 전달할 문장

현재 개발을 계속하면서 첨부한 v4 에셋팩을 연결해줘. 먼저 README.md, QA_REPORT.md, docs/INTEGRATION.md를 읽고 기존 프로젝트의 에셋 임포터·레지스트리와 대조해줘. manifest.json은 ID와 애니메이션 키 단위로 병합하고 기존 idle·공격·보스 기믹을 보존해줘. audio_manifest.json의 오디오도 연결해줘. 실제 테스트한 것과 아직 확인하지 않은 것을 구분해서 알려줘.

내가 특히 확인할 것은 새 직업 3종의 4방향 동작, 적 사망, 보스 탈피·뿌리 재생, 카드 설명 영역, 물가 모서리, NPC, 1~4인 전투에서의 효과음과 서버 상태 동기화야. 문제가 있으면 에셋 ID·상태·방향·프레임과 스크린샷으로 정리해줘.

편집 원본 ZIP은 그림을 수정할 때만 추가로 사용하면 돼. 후속 에셋은 기존 ID·규격·앵커·매니페스트 형식에 맞춰 이 프로젝트에서 계속 제작해줘.
