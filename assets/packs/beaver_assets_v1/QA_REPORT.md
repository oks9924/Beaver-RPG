# 에셋팩 v1 검수 기록

검수일: 2026-09-20. 상태: **개발 연결용 초안**.

## 확인 완료

| 항목 | 결과 |
|---|---|
| 캐릭터 수 | 플레이어 5 + 일반 적 12 + 보스 3 = 20 |
| 개별 프레임 수 | PNG 160개, 서로 다른 파일 해시 160개 |
| 원본 시트 | PNG 25개, 각 1254×1254 |
| 플레이어/일반 적 프레임 | 128×128 RGBA |
| 보스 프레임 | 512×512 RGBA |
| 알파 | 각 프레임에 완전 투명 픽셀과 완전 불투명 픽셀 존재 |
| PNG 디코딩 | 개별 프레임 160개와 원본 25개 전체를 끝까지 읽어 확인 |
| 가장자리 | 출력 테두리에 알파 30 초과 픽셀 없음 |
| 애니메이션 중복 | 4프레임 동작 안에 동일한 파일을 반복 삽입한 경우 없음 |
| 리소스 경로 | SpriteFrames 20개의 참조 PNG 경로 존재 확인 |
| 미리보기 JavaScript | Node 구문 검사 통과 |
| 육안 확인 | 원본 시트 및 최종 수호목수 공격/E/R 시퀀스, 전체 20종 정면 목록 확인 |

출력 테두리 검사는 파일 분할로 그림이 잘렸는지 점검하는 지표입니다. 원본 해부학·완전한 포즈 일관성·프레임 간 자연스러운 움직임까지 자동 보증하지는 않습니다.

## 개발 환경에서 추가 확인할 항목

- Godot 실행 파일이 없어 `.tres` import, GDScript 실행, 실제 씬 배치, Windows export는 실행 검증하지 않았습니다.
- 로컬 브라우저 실행 환경이 없어 `preview.html`의 브라우저 실제 구동은 검증하지 않았습니다. 파일 참조와 스크립트 구문을 확인했습니다.
- 캐릭터들의 전체 색·비율은 같은 스타일을 따르지만 강한 모션에서 몸 중심과 장비 세부가 달라집니다. 애니메이션은 1차 초안으로 관리합니다.
- 발 기준점은 실사용을 위한 정렬 후보입니다. 제자리 걸음과 방향 전환을 엔진에서 재생해 발 미끄러짐·몸 크기 변화를 보정합니다.
- 수호목수 R 일부 프레임은 측면에서 정면 쪽으로 고개가 돌아옵니다. 최종 방향 일관성 보정 대상입니다.
- 적·보스의 기본 자세는 전투 동작을 대체하지 않습니다. 이동/공격/피격/사망과 기믹 전용 VFX를 별도로 제작합니다.
- 이미지에는 충돌 반경, 실제 피해 프레임, 보스 공략 판정이 들어 있지 않습니다. 서버 게임 데이터와 별도로 연결해야 합니다.

검수 중 발견한 빈 알파 프레임과 불완전하게 기록된 PNG는 재출력했고, 최종 전체 파일 검사를 통과한 자료를 패키지에 넣었습니다.
