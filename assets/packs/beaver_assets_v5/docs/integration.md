# 연결 규칙

## UI 인덱스

| ID | 인덱스 | 의미 |
|---|---:|---|
| ui.frame.rarity | 0 | 일반 / #ffffff |
| ui.frame.rarity | 1 | 고급 / #7be07b |
| ui.frame.rarity | 2 | 희귀 / #6fb6ff |
| ui.frame.rarity | 3 | 영웅 / #c58cff |
| ui.frame.rarity | 4 | 전설 / #ffb347 |
| ui.slot.gear | 0 | 빈 무기 슬롯 |
| ui.slot.gear | 1 | 빈 갑옷 슬롯 |
| ui.slot.gear | 2 | 빈 장신구 슬롯 |
| ui.slot.gear | 3 | 잠긴 슬롯 |

위 두 시트는 시간에 따라 재생하지 않는다. `playback_mode=select_frame`, fps=0이며 프레임 인덱스를 직접 선택한다. 기존 importer가 fps=0을 허용하지 않으면 내부 기본 fps는 유효한 값으로 저장하되 자동 재생을 비활성화한다. 단일 아이콘도 정적 프레임이다.

시트 영역은 `Rect2(index * frame_width, 0, frame_width, frame_height)`다. margin=0, spacing=0. 외곽 사각형으로 시트를 전체 표시하면 여러 등급이 한꺼번에 보이므로 반드시 영역을 선택한다. 실제 프로젝트의 Godot 버전과 노드 방식에 맞춰 AtlasTexture 또는 region을 사용한다.

## 크기와 레이어

장비·재료·도안은 64×64 캔버스 중앙에 최대 48×48의 그림이 들어간다. 등급 테두리의 정확한 투명 영역은 x=8..55, y=8..55다. RGB 색상 정보가 투명 픽셀에 남아 있어도 alpha=0이면 정상이다. 테두리 본색은 요청한 정확한 HEX이며, 바깥쪽 홈에만 어두운 음영이 들어간다.

권장 표시 순서: UI 바탕 → 장비 아이콘 → 등급 테두리 → 제작품/잠금 상태 표시 → 강화 배지 → 코드로 쓴 +N → 강화 결과 VFX. 빈 슬롯 문양은 비어 있을 때만 보여 준다. 아이템을 장착한 뒤 문양과 아이콘을 동시에 겹치지 않는다.

강화 배지는 24×24의 빈 목재 바탕이다. +0/+9/+10/+20처럼 실제 게임에서 허용하는 최장 문자열이 중앙에 들어가는지 확인하고 글꼴 크기·외곽선을 조절한다. 제작품 망치 24×24와 도안 잠금 자물쇠 32×32는 서로 다른 용도다. UI 배율 변경 시 그림의 종횡비를 유지한다.

## 강화 연출

| 결과 | 프레임 | 캔버스 | FPS | VFX 길이 | SFX 길이 |
|---|---:|---|---:|---:|---:|
| success | 6 | 96×96 | 12 | 0.50초 | 0.75초 |
| fail | 4 | 96×96 | 10 | 0.40초 | 0.55초 |
| destroy | 8 | 128×128 | 10 | 0.80초 | 0.85초 |

실패 VFX의 길이는 요청서에 지정되지 않아 0.40초로 정했다. 성공·파괴는 요청 길이를 따른다. VFX와 효과음은 같은 순간에 시작하되 각 파일이 끝날 때까지 독립적으로 재생한다. VFX 종료 때문에 남은 효과음을 잘라내지 않는다.

모든 VFX는 one_shot, loop=false, hold_last_frame=false, hide_after_last_frame=true다. 각 프레임은 동일한 크기이며 프레임별 자동 trim/크기 맞춤을 다시 하지 않는다. 원점은 프레임 중심이다. 마지막 프레임을 영구 표시하지 말고 정해진 재생 시간 뒤 노드를 숨기거나 해제한다. PNG의 기본 알파 합성으로 사용하며 검은 배경 텍스처가 아니다.

서버가 재료 소모·강화 결과·장비 상태를 확정한 응답을 받은 뒤 해당 결과를 재생한다. 재전송된 동일 결과, 재접속 시 상태 복원, UI 재진입 때문에 같은 연출을 다시 재생하지 않는다. 연출은 결과 표시만 담당하며 강화 확률·성공 여부·소모량을 결정하지 않는다. 빠른 연속 강화에서 이전 노드가 남거나 소리가 무제한 겹치지 않도록 결과별 재생을 관리한다.

## 기존 프로젝트 병합

1. 프로젝트 `docs/asset_plan.md`, importer, registry, `_item_button`을 먼저 읽는다.
2. 팩의 actors 키와 audio 키를 요청 ID 그대로 대응시킨다. 점을 밑줄로 바꾼 새 ID를 만들지 않는다.
3. 기존 구조에 맞춰 경로를 등록하고, 이미지 로딩 성공 후 렌더링에 사용하는 레지스트리 항목을 final로 표시한다. 프로젝트 전체 매니페스트를 이 팩 파일로 대체하지 않는다.
4. 사용자 요청에 명시된 `tools/import_asset_pack.gd --packs=` 경로를 사용하되, 실제 CLI 인자 형식은 해당 코드에서 확인한다. 확인되지 않은 실행 명령을 이 문서에서 확정하지 않는다.
5. 한 장비의 일반/전설 표시부터 확인하고 모든 등급·슬롯·배지·도안·강화 결과로 넓힌다. 기존 아이콘이 없는 항목의 텍스트 fallback도 유지한다.

## 실제 클라이언트 확인 항목

- 장비 17종은 올바른 base ID에 연결되고 전설 9종이 기본 아이콘을 공유한다.
- 테두리는 지수 0~4로 정확히 선택되고 장비를 가리지 않는다.
- 빈 슬롯 4종, 제작 망치, 잠금 자물쇠가 올바른 상태에서만 표시된다.
- 배지 +N이 코드에서 그려지고 최대 강화값도 잘리지 않는다.
- 강화 성공/실패/파괴가 서버 결과와 일치하고 한 번만 재생된다.
- 강화 VFX가 끝나면 사라지고, 빠른 연속 작업·재접속·UI 재진입에서도 잔상이 없다.
- 1~4인 접속 클라이언트에서 타인의 결과가 잘못 재생되지 않는다. 공용 연출 여부는 기존 게임 설계를 따른다.
