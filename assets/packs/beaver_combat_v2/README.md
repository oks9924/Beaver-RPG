# 꼬리원정대 — 몬스터·보스 전투 애니메이션 v2

기존 에셋팩과 같은 외형을 기준으로 제작한 **개발 연결용 4프레임 애니메이션 초안**입니다. 일반 몬스터 12종, 보스 3종의 기본 공격, 보스 시전/경직과 독립 기믹 15종의 장치 연출을 포함합니다.

## 구성

| 항목 | 구성 | 새 PNG 수 |
|---|---|---:|
| 일반 몬스터 공격 | 12종 × 공격 1개 × 4방향 × 4프레임 | 192 |
| 보스 기본 공격 | 3종 × 공격 4개 × 4방향 × 4프레임 | 192 |
| 보스 기믹 시전·약점 노출/경직 | 3종 × 상태 2개 × 4방향 × 4프레임 | 96 |
| 독립 기믹 장치 | 15종 × 진행/성공/실패 3상태 × 4프레임 | 180 |
| 신규 합계 | 원본 시트 45장 | **660** |

기존 일반 적·보스의 4방향 기본 자세 60개도 복사해 포함합니다. 따라서 이 팩에 연결된 PNG는 **720개**입니다. 플레이어 직업의 이미지와 애니메이션은 기존 v1 팩을 사용합니다.

보스의 기본 공격 4개와 독립 기믹 5개를 별도 ID로 구분했습니다. 공통 시전·경직 자세는 여러 기믹이 공유합니다. 기믹별 구별되는 장치/상호작용 연출은 각자의 12프레임 시트에 들어 있습니다.

## 빠르게 사용

1. 압축을 풀고 `beaver_combat_v2/preview.html`을 엽니다.
2. 대상과 동작을 선택합니다. 몬스터/보스는 4방향, 기믹 장치는 진행·성공·실패를 나란히 확인합니다.
3. `beaver_combat_v2` 폴더를 Godot 프로젝트 루트에 복사합니다.
4. 에셋 레지스트리에서 해당 몬스터·보스 ID가 이 팩의 `godot/resources/*.tres`를 읽도록 연결합니다.
5. `INTEGRATION.md`의 상태·이벤트 연결 규칙에 따라 게임의 서버 상태와 동기화합니다.

로컬 HTML은 에셋 검수 도구입니다. 설치형 게임 클라이언트·독립 전용 서버 구조를 유지합니다.

장치별 상태는 `activation_fixed`, `success_fixed`, `failure_fixed`입니다. `fixed`는 고정 카메라의 한 방향이라는 뜻입니다. 장치는 몸체와 별도 리소스이며 몸 애니메이션 4방향에 억지로 대응시키지 않습니다.

장치 시트에는 상호작용 과정을 한 덩어리로 확인할 수 있는 조합형 그림이 포함됩니다. IC-03 집게 잠금은 부착용 확대 연출이고, TF-01 씨앗 운반·RK-03 이식 등은 장치에서 일어나는 시각 상태를 제공합니다. 운반 물체의 독립 이동, 여러 지점에 놓인 논리 노드, 수로의 실제 연결 관계는 게임의 별도 오브젝트로 구현합니다. 씬 전체나 플레이어의 모든 상호작용 동작을 이미지 안에 포함하지 않았습니다.

## 규격과 파일

- 일반 몬스터: 128×128 RGBA PNG, 발 기준점 후보 `(64,106)`.
- 보스: 512×512 RGBA PNG, 발 기준점 후보 `(256,424)`.
- 기믹 장치: 256×256 RGBA PNG, 기준점 후보 `(128,212)`.
- 원본은 생성된 크기를 그대로 보존하고, 실제 크기·분할 영역·출력 배치는 `manifest.json`에 기록합니다. 512px 파일이라고 원본 디테일이 512px로 그려졌다는 의미는 아닙니다.
- 일반 적 공격 8 FPS, 보스 6 FPS, 장치 진행 6 FPS·성공/실패 8 FPS가 미리보기 기본값입니다. 게임 밸런스 확정값이 아닙니다.
- 전투·기믹 애니메이션은 단발입니다. 기본 자세만 반복 설정입니다.
- `source_sheets/`: 고해상도 원본 45장.
- `assets/`: 방향별/상태별 개별 PNG.
- `godot/resources/`: 몸체 15개 + 기믹 장치 15개의 SpriteFrames.
- `godot/CombatVisual.gd`: 재생 및 서버 진행률을 전달받는 시각 연결 예제.
- `manifest.json`: ID·프레임·FPS·기믹 매핑·인원 조정 정보.
- `generation_prompts.json`: 실제 생성 프롬프트와 제작 방식.
- `QA_REPORT.md`: 검증 결과와 남은 확인 항목.
- `preview.gif`: 보스 공격 3종과 기믹 3종의 간단한 반복 미리보기. GIF의 반복과 프레임 유지 시간은 소개용이며 실제 게임 타이밍과 무관합니다.

## 구현 범위

일반 몬스터/보스의 공격 준비·공격·회복 포즈와 기믹 장치의 상태 전환을 제공합니다. 4프레임 사이의 부드러운 보간, 몸 비율·발 위치·장비 방향의 세부 보정, 이동·피격·사망·개별 운반물 애니메이션은 후속 제작 범위입니다.

몸 그림에 가까운 발사 잔상이나 작은 충격 효과가 들어 있습니다. 실제 투사체 비행, 길게 뻗는 혀/급류, 전장 전체 장판과 충격파는 서버가 정한 좌표·범위에 별도 렌더링해야 합니다. 정밀한 위험 예고 도형은 게임 좌표에서 그려야 공격 판정과 맞출 수 있습니다.

이 팩은 아트와 연결 자료입니다. 보스의 15개 기믹 로직, 1~4인 난이도 조절, 네트워크 동기화는 기존 제작 MD를 따라 게임 코드에서 구현합니다. 애니메이션이 재생된다는 사실만으로 기믹 구현 완료로 기록하지 않습니다.

내장 이미지 생성 기능으로 제작한 원본을 기준으로 파일을 분할·정렬했습니다. PNG·경로·프레임 구성은 검사하며, Godot import/실행 및 클라이언트 export 여부는 `QA_REPORT.md`에 구분해 기록합니다.
