## 시각 검토

생성 원본과 추출 프레임의 대표 정지 화면을 확인했습니다. 사수 신호 동작의 중복 무기, 가재 배경 투명도, 사망 시트의 프레임 접촉 문제를 수정했습니다. GIF는 여섯 대상의 대표 동작을 반복하는 소개용이며 게임의 실제 공격 속도·피격 판정·월드 크기를 보여주지는 않습니다.

생성 작화 특성상 손·무기·얼굴·갑각의 디테일과 실루엣에 프레임 간 차이가 남을 수 있습니다. 대표 정지 화면 확인과 PNG 기술 검사는 출시 품질의 전체 애니메이션 재생 검수를 대신하지 않습니다.

## 개발 프로젝트에서 확인할 항목

- 실제 `tools/import_asset_pack.gd`, `check_assets`, Godot 실행 및 데모 캡처 검사는 여기서 수행하지 않았습니다. 프로젝트 소스와 런타임이 제공되지 않았습니다.
- `preview.html`은 브라우저 실행 검증 없이 구문만 검사했습니다.
- 기존 actor 전체를 교체하지 말고 animation 단위로 병합합니다. 기존 idle·v2 공격을 유지합니다.
- `husk_all`의 애니메이션별 256px 크기와 앵커 우선 적용을 확인합니다.
- 4방향 재생 시 발 위치 흔들림, 비대칭 장비의 손 위치, 상태 전환 순간의 크기 차이를 실제 카메라에서 확인합니다.
- 단발·반복·다운 유지와 서버 상태 전환을 맞춥니다. visual_contact_frame에서 게임 판정을 새로 발생시키지 않습니다.
- 철턱 가재 `molt`는 껍질이 갈라져 밝은 내부가 보이는 전환 동작입니다. 완전히 탈피한 몸체의 이동·공격 전체 세트는 이번 범위에 없습니다.

자동 검사 수치와 미수행 런타임 항목은 `qa_results.json`에 기록했습니다. 실제 개발 프로젝트 검수 결과가 있으면 이 보고서와 대조할 수 있습니다.
