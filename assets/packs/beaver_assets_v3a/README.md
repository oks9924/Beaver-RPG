# 꼬리원정대 — 에셋팩 v3-A

`asset_request_v3.md`의 **우선순위 A 전체**를 담는 추가 에셋팩입니다. 기존 v1·v2에 없는 동작만 제공합니다. v1·v2가 연결된 프로젝트에 애니메이션 단위로 병합하세요.

## 구성

| 대상 | 추가 상태 | 원본 수 | 개별 PNG |
|---|---|---:|---:|
| 솔방울사수 | walk, attack, cast_q, cast_e, cast_r, hit, down, death | 8 | 112 |
| 수호목수 | hit, down, death, interact | 4 | 48 |
| 수액 달팽이 | walk, hit, death | 3 | 40 |
| 가시 멧돼지 | walk, hit, death, charge | 4 | 56 |
| 검은 까마귀 | walk, hit, death | 3 | 40 |
| 철턱 가재 | walk, hit, death, molt, husk | 5 | 65 |
| 합계 | 방향별/공용 애니메이션 105개 | **27** | **361** |

요청서 요약의 대략치가 아니라 각 상세 표를 합산했습니다. 철턱 가재 사망은 일반 공통값 4가 아닌 해당 상세 표의 **방향당 6프레임**입니다. 빈 껍질은 공용 1프레임입니다.

이번 묶음에 B(VFX), C(타일·소품), D(아이콘), E(UI)는 들어 있지 않습니다. F(후속 콘텐츠)와 G(오디오)도 미제작입니다. 요청서에서 허용한 A 선납품이며 v3 전체 완료를 뜻하지 않습니다.

## 파일 구조와 확인

- `manifest.json`: 요청한 format_version 2, actor별 animation 상태·방향·FPS·반복·프레임·시각 발동 메타데이터.
- `assets/<actor>/<state>/<direction>_NN.png`: 실제 사용하는 개별 RGBA PNG.
- `source_sheets/`: 생성 원본 27장. 행·열을 곧바로 균등 분할한 결과가 아니므로 실제 사용에는 assets 또는 manifest를 사용합니다.
- `godot/resources/*_additions.tres`: 새 동작만 포함한 SpriteFrames 6개. 기존 전체 리소스를 이 파일로 통째로 교체하지 말고 동작을 병합합니다.
- `preview.html`: ZIP을 푼 뒤 열어 대상·동작·방향·반복·앵커를 확인하는 로컬 검수 도구.
- `preview.gif`: 대표 동작을 반복하는 간단한 소개용 미리보기.
- `INTEGRATION.md`: 기존 임포트 도구에 추가하는 방법과 크기 예외.
- `QA_REPORT.md`, `qa_results.json`: 실제로 수행한 검사와 미검증 항목.
- `generation_prompts.json`: 내장 이미지 생성 기능으로 제작한 실제 프롬프트.
- `docs/asset_request_v3.md`: 납품 기준이 된 요청서 사본.

## 규격

일반 캐릭터/적은 128×128, 발 기준점 `(64,106)`입니다. 철턱 가재 몸체는 512×512, `(256,424)`입니다. 빈 껍질 `husk_all`만 256×256, `(128,212)`입니다. 크기와 기준점은 **애니메이션 항목에도 기록**되어 있습니다.

`down/right/up/left` 방향은 독립적으로 생성했습니다. 좌우 반전이나 기존 이미지의 회전·색 변경으로 새 동작을 대신하지 않았습니다. 출력 과정에서는 프레임 분할, 이웃 프레임 제거, 균일 비율 축소/확대와 투명 캔버스 정렬을 수행했습니다.

그림의 디테일과 동작은 개발 연결용 초안입니다. 이미지 생성 결과의 프레임 간 손·장비·신체 비율 차이는 실제 게임 카메라에서 확인하고 보정할 수 있습니다. PNG가 기술 검사를 통과했다는 사실과 출시용 작화 검수 완료는 구분합니다.
