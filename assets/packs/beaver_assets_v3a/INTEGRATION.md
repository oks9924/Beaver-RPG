# v3-A 연결 지침

현재 프로젝트는 요청서에 기재된 **단계 2 코드 완료, v1·v2 연결 완료** 상태를 전제로 합니다. 기존 대기·공격·스킬과 저장 데이터는 그대로 두고 이번에 추가된 동작을 등록합니다.

## 임포트

1. `beaver_assets_v3a/`를 프로젝트에서 읽을 수 있는 위치에 배치합니다. 제공 `.tres`의 경로는 `res://beaver_assets_v3a/`입니다. 다른 위치로 이동하면 참조를 함께 바꿉니다.
2. 기존 `tools/import_asset_pack.gd`로 `manifest.json`을 읽고 `actors[actor_id].animations[animation_name]` 단위로 병합합니다. actor 전체를 덮어쓰면 v1·v2의 동작이 사라질 수 있습니다.
3. 애니메이션 이름은 `walk_down`, `cast_q_down`, `interact_left`, `molt_up`, `husk_all`처럼 요청서의 상태명과 방향을 그대로 사용합니다. 게임 내부 상태와의 매핑은 기존 임포트 도구가 담당합니다.
4. 기본 자세 등 이미 있는 파일은 이 ZIP에 재포함하지 않았습니다. 파일 누락으로 오인해 기존 리소스를 비우지 마세요.
5. `.tres`를 직접 사용하는 경우에도 각 additions 리소스의 애니메이션을 기존 SpriteFrames에 합칩니다. 이번 팩의 리소스만 연결하면 기본 자세가 없습니다.

임포트 도구의 실제 소스와 게임 실행 환경은 제작 쪽에 제공되지 않았습니다. 이번 팩에서는 요청서에 적힌 JSON·경로 규격을 검사했으며 프로젝트 임포트 실행은 개발 쪽에서 확인해야 합니다.

## 빈 껍질의 크기 예외

`actors.boss_ironclaw.animations.husk_all`은 요청대로 256×256입니다. 같은 actor의 다른 동작은 512×512입니다.

각 애니메이션의 `frame_size`, `anchor_px`가 actor 기본값보다 우선합니다. 임포터가 actor 기본 크기만 사용하는 경우, 이 두 필드의 우선 처리를 추가하거나 `husk_all`을 별도의 껍질 노드로 옮겨 연결하세요. 껍질은 본체의 Sprite 노드를 교체하는 용도보다 IC-04의 별도 가짜 위치 오브젝트에 적합합니다.

보스를 게임에서 512→256으로 표시하는 배율과 껍질의 최종 월드 크기를 별도로 조절합니다. 폴더를 근거로 껍질을 다시 절반 크기로 줄이지 않습니다. 크기·앵커는 픽셀 단위이며 월드 충돌 범위와 독립입니다.

## 재생 규칙

| 상태 | 프레임/방향 | 기본 재생 |
|---|---:|---|
| walk | 4 | 이동 상태에서 반복 |
| charge | 4 | 서버 돌진 상태 동안 반복 |
| interact | 4 | 갉기 상호작용 중 반복 |
| attack, cast_q/e/r | 4 | 단발, 다음 서버 상태로 전환 |
| hit | 2 | 단발, 이전/다음 전투 상태로 복귀 |
| down | 2 | 단발 후 마지막 자세 유지 |
| death | 일반 4 / 철턱 가재 6 | 단발 후 마지막 자세 유지 |
| molt | 4 | 단발, 탈피 기믹 상태에 맞춰 유지·전환 |
| husk | 공용 1 | 정적 이미지 |

`visual_contact_frame`은 0부터 세며 사수의 attack/Q/R은 2, E는 3입니다. 별도 시각 발동 지점이 없는 항목은 **-1**입니다. 이 값에서 서버 피해나 덫 생성 판정을 실행하지 않습니다. 서버 이벤트가 실제 발사·설치·상호작용 성공을 결정합니다.

`hold_last_frame`은 사용자의 재생 코드에서 적용할 메타데이터입니다. 피격 포즈를 계속 유지하는지, 원래 이동으로 돌아가는지는 서버 전투 상태가 결정합니다. 단발 완료 후 모든 상태를 무조건 idle로 보내지 않습니다.

다운 2프레임은 다운 자세에서 약하게 가라앉는 동작입니다. 계속 호흡하는 별도 순환이 필요하면 마지막 자세에 작은 시각 호흡 효과를 적용하거나 추가 프레임을 제작하세요. 다운 진입을 반복 재생해 벌떡 일어나거나 몸이 튀게 만들지 않습니다.

## 개별 연결 유의사항

- 가시 멧돼지 `charge`는 지속 돌진 중의 보행 주기입니다. v2의 공격 예고·접촉·회복 상태와 역할을 나눕니다.
- 까마귀 `walk`는 요청한 낮은 비행 동작입니다. 지면 그림자·높이는 게임 노드에서 관리합니다.
- 사수 `cast_e`에 작은 덫 설치 그림이 포함되어 있습니다. 배치된 실제 덫은 서버 생성 오브젝트로 따로 관리하고, 마지막 캐릭터 프레임 속 그림과 장시간 중복 표시하지 않습니다.
- 가재 `molt`는 본체와 벗겨지는 갑각이 한 프레임에 들어 있는 전환 연출입니다. 탈피 이후의 모든 일반 공격을 위한 별도 밝은 몸체 세트까지 포함하지는 않습니다. 본체 연출 종료 시점과 정적 `husk_all` 생성 시점을 맞춥니다.
- 수호목수 `interact`는 앞니 갉기 포즈입니다. 목재 감소·지지목 약화 완료는 서버 상호작용 진행도로 결정합니다.

## 개발자에게 바로 전달할 지시

이 팩은 `asset_request_v3.md`의 A 묶음이다. 기존 v1·v2 위에 애니메이션 단위로 병합하고, `husk_all`의 256px 예외와 상태별 반복 여부를 반영해줘. 현재 파생본으로 표시하던 이동·피격·다운·사망·탈피 자리에 새 동작을 연결한 뒤 `check_assets`와 데모 화면으로 확인해줘. B~G는 이번 납품에 포함되지 않으므로 기존 미완성 목록을 유지하고, 실제 검사 결과와 남은 항목을 보고해줘.
