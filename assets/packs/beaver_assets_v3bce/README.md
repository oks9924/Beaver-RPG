# 꼬리원정대 — 에셋팩 v3 B~E

`asset_request_v3.md`의 B(스킬 VFX·투사체), C(버들강 지형·소품), D(아이콘), E(UI)를 담은 추가 팩입니다. 앞서 전달한 v3-A와 함께 사용합니다. 기존 v1·v2·v3-A 파일은 이 ZIP에 재포함하지 않습니다.

| 묶음 | 팩 ID 수 | 개별 PNG 수 |
|---|---:|---:|
| B: VFX·투사체 | 16 | 64 |
| C: 지형 6종·소품 13종 | 19 | 53 |
| D: 스킬·회복·회피·유물·상태 아이콘 | 24 | 24 |
| E: UI 및 변형·레이어 | 9 | 17 |
| 합계 | **68** | **158** |

요약표의 대략치 대신 상세 표를 기준으로 제작했습니다. 강둑은 설명에 기재된 상하좌우 경계와 안쪽 모서리를 모두 포함하기 위해 **전체 1 + 경계 4 + 모서리 4 = 9장**을 제공합니다. 작업실은 상세 표대로 0/1/2단계 3장입니다.

## 빠른 사용

1. `INTEGRATION.md`를 먼저 읽습니다.
2. `beaver_assets_v3bce/`를 프로젝트에 배치하고 `manifest.json`을 기존 임포트 도구에서 읽습니다.
3. 새 actor와 `default_all` 항목을 등록하고, 기존 v1·v2·v3-A 동작을 보존합니다.
4. `frame_labels`, `playback_mode`, `segments`를 보고 상태 선택·반복·단발을 구분합니다.
5. 게임에서 `check_assets`와 데모 재생으로 판정 예고의 가독성·소품 위치·타일 연결·UI 크기 변화를 확인합니다.

## 포함 파일

- `assets/<id>/default/all_NN.png`: 게임에서 사용하는 개별 PNG.
- `manifest.json`: format_version 2, 크기·앵커·순서·재생 메타데이터.
- `ASSET_INDEX.md`: 모든 ID와 프레임 의미 목록.
- `source_sheets/`: 이미지 생성 원본. 실제 임포트는 분리된 assets 파일을 사용합니다.
- `generation_prompts.json`: 내장 이미지 생성 기능으로 제작한 실제 프롬프트.
- `preview.html`, `manifest.js`: 설치 없이 여는 에셋 검수 화면. 게임 클라이언트가 아닙니다.
- `preview.gif`, `contact_sheet.png`: 대표 효과 미리보기와 카탈로그.
- `QA_REPORT.md`, `qa_results.json`: 실제 검사 결과와 미검증 범위.
- `qa_previews/`: 지형 연결·VFX 전 프레임·체력바 합성·9-slice 확대 검수 이미지.
- `docs/asset_request_v3.md`: 기준 요청서 사본.

게임에 사용하는 `assets/`의 158장은 모두 RGBA PNG입니다. VFX·아이콘·소품·프레임의 빈 부분은 실제 투명이며, 바닥과 물 같은 면 타일은 지면을 채우기 위해 불투명합니다. `source_sheets/`는 생성 원본을 보존하므로 일부 면 타일은 RGB입니다. 글자는 이미지에 넣지 않았으며 제목·버튼·카드 내용은 클라이언트에서 그립니다.

이 팩은 **개발 연결용 작화 초안**입니다. 이미지 생성 원본을 프레임별로 분리하고 크기를 맞춘 결과이며, 실제 엔진에서의 재생·타일 접합·입력 상태 연결까지 검수한 출시용 게임 빌드는 아닙니다. F(후속 직업·적·보스·NPC·지역)와 G(오디오)는 포함하지 않습니다.
