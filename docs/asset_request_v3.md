## 1. 공통 규칙 (v1·v2 와 동일, 변경 없음)

- 화풍: v1 `player_guardian`, v2 `boss_ironclaw` 원본 시트를 기준으로 둥근 몸·짧은 팔다리·큰 앞니·넓은 꼬리, 따뜻한 숲색 수채화풍 부드러운 명암, 또렷한 윤곽. 3/4 탑다운 고정 카메라, 광원 화면 좌상단.
- 방향: `down, right, up, left` 4방향. 좌우 반전 금지(무기·장비 비대칭).
- 프레임: 플레이어·일반 적 128×128, 보스 512×512(우리가 256 으로 줄여 씀), 장치·소품 256×256, 타일 64×64, 아이콘 64×64, 초상 256×256, VFX 128/256/512 정사각.
- 발 앵커: 128 프레임 (64,106), 512 프레임 (256,424). 프레임 안에서 발 위치·스케일·여백을 고정한다. 무기 손잡이·꼬리·의상·얼굴이 프레임마다 바뀌지 않는다.
- 배경: 실제 알파 투명. 체크무늬가 픽셀에 박힌 이미지는 받지 않는다. 이미지 안에 글자 금지.
- 프레임 수: 대기 2, 이동 4, 공격 4, 시전 4, 피격 2, 다운 2, 사망 4, 탈피 4. 장치 4. VFX 4~6.
- 납품 형식: v2 와 같은 구조. `manifest.json`(format_version 2) 의 `actors[<id>].animations[<state>_<dir>]` 에 `state, direction, fps, loop, frames[], hold_last_frame, visual_contact_frame` 을 적고, 프레임 파일은 `assets/<actor>/<state>/<dir>_NN.png`. 방향이 없는 항목(타일·VFX·아이콘·UI·소품)은 `direction: "all"` 로 두고 프레임을 `assets/<actor>/<state>/all_NN.png` 로 둔다. 우리 임포트 도구(`tools/import_asset_pack.gd`)가 이 형식을 그대로 읽는다.
- 상태 이름은 아래 표의 **팩 상태명** 을 그대로 쓴다. 내부 ID 매핑은 우리가 한다.
