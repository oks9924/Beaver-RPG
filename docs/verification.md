## 발견·수정한 결함
- **export 빌드에서 모든 에셋이 대체 도형으로 표시됨** (Windows 실기에서 발견). 원인: pck 에는 원본 png/ttf/wav 가 아니라 import 된 리소스만 들어가는데 AssetRegistry 가 원본 파일 존재만 확인했다. 초기 Linux 검증은 프로젝트 폴더에서 실행해 원본을 읽는 바람에 통과했다. 수정: `ResourceLoader.exists` 로도 해석하고, export 스모크 테스트를 프로젝트 밖 폴더에서 실행하도록 바꿨다.

## 화면 검증 (Xvfb + Mesa llvmpipe, OpenGL3 호환 렌더러)
- 클라이언트 데모 모드(`--demo=<nick> --shots=<dir>`)로 실제 클라이언트를 가상 디스플레이에서 실행해 로그인·마을·파티·전투·결과 화면을 캡처했다. `docs/screenshots/` 참고.
- 확인한 것: 한국어 폰트 렌더링, 임시 비버/달팽이 스프라이트와 4방향·공격 애니메이션, 적 강공격 예고(주황 링+채워지는 원), HUD(체력·회피 충전·Q/E/R 아이콘·회복 횟수·파티 상태·웨이브), 결과 화면과 보상, 개발 화면(F3).
- 확인하지 못한 것: 실제 키보드·마우스 **조작감**, 60fps 성능(소프트웨어 렌더러 기준 70~140fps 는 참고값일 뿐), Windows 실기 실행, 인터넷 지연 환경.
- Windows 클라이언트 export 는 preset 만 준비했다. CI(GitHub Actions) 가 `TailExpedition.exe` 를 만들며, 실제 Windows 실행은 사용자가 확인해야 한다.

## 성능 메모 (측정값, 보장 아님)
- 서버 틱: 4인 원정 1개 + 마을 2명 기준 평균 0.1ms 미만, 최대 수 ms (컨테이너, 봇 클라이언트). `server_status.json` 과 로그 metrics 줄에 기록된다.
- 전투 스냅샷(4인, 적 ~7): 패킹 후 ENet MTU(1392B) 안에 들어온다. 통합 테스트 서버 로그에 MTU 경고 0회.
