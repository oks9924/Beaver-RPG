# 에셋 요청 v6 — 걷기 동작 재작업 (2026-09-21)

실기에서 걷기가 "잔상이 남는 것처럼" 보이는 원인이 걷기 시트에 있습니다. 현재 5직업 걷기 시트(`char.<class>.walk`, 4방향 × 4프레임, 128×128)는 4프레임이 **한 걸음의 연속 동작이 아니라 서로 다른 그림**이라 프레임마다 몸 크기·팔·방패 위치가 바뀝니다. 8fps 로 돌리면 깜빡임으로 보입니다. 측정(알파 경계 상자, 가로 폭):

| 시트 | 아래(row0) 4프레임 가로 폭 | 왼쪽(row2) |
|---|---|---|
| char.guardian.walk | 84 / 79 / 82 / 72 | 85 / 84 / 84 / 80 |
| char.hydro.walk | 73 / 66 / 69 / 75 | 85 / 84 / 82 / 85 |
| char.pinecone.walk | 80 / 78 / 78 / 82 | 88 / 86 / 86 / 87 |

같은 이유로 공격 시트(`char.<class>.attack`)도 프레임마다 몸 크기가 달라 흔들립니다(수호목수 row1 높이 81/93/71/76).

## 요청 (ID·규격은 그대로, 파일만 교체)
| ID | 요청 | 규격 |
|---|---|---|
| char.guardian.walk, char.sawtooth.walk, char.pinecone.walk, char.sapshaman.walk, char.hydro.walk | **한 캐릭터를 고정**하고 다리·팔만 움직이는 걷기 순환. 프레임 순서 0→1→2→3→0 이 이어지게(접지 – 통과 – 접지 – 통과). 몸통·머리·장비의 위치와 크기는 4프레임 모두 같게, 발 끝 y 는 고정 | 4방향 × 4프레임, 128×128, 시트 512×512, 앵커(0.5, 0.82) |
| char.<class>.attack (5종) | 휘두르기 4프레임: 준비 – 휘두름 – 끝 – 복귀. 몸통 크기 고정, 무기만 크게 움직임 | 4방향 × 4프레임, 128×128 |
| (선택) char.<class>.walk 6프레임 | 4프레임으로 부족하면 6프레임(768×512)도 받습니다. 매니페스트 `columns`·`frames` 만 바꾸면 됩니다 | 4방향 × 6프레임 |

## 제작 지침
- 4프레임을 따로 생성하지 말고 **1프레임을 만든 뒤 팔·다리만 바꾼 파생**으로 만들어 주세요. 실루엣을 겹쳐 봤을 때 몸통이 겹쳐야 합니다.
- 각 방향(아래·위·왼·오른)은 같은 몸 크기. 왼쪽/오른쪽은 좌우 반전이어도 됩니다.
- 배경 투명, 외곽선·색은 v3a 와 동일. 파일 이름·시트 배치는 v3a 와 같게 (`beaver_assets_v3a` 의 `actors/` 규칙, START_HERE 에 명시).

## 납품 후 절차
`tools/import_asset_pack.gd --packs=` 로 다시 임포트하면 매니페스트 ID 가 같으므로 코드 변경 없이 교체됩니다. `check_assets` 0 문제 확인 뒤 `docs/screenshots/room_density_4p.png` 를 다시 찍어 비교합니다.
