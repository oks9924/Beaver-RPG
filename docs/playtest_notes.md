# 플레이 관찰과 대응안

## 2026-09-20 · 사용자 1인 실기 (v2 연결 빌드)

관찰: 보스 처치까지 약 5분. 기믹이 단순함. 방마다 적이 적음.

### 현재 수치 (왜 5분인가)
| 항목 | 현재 값 | 효과 |
|---|---|---|
| 경로 | 5층 중 전투 2~3방, 나머지 사건·상점·휴식 | 실제 전투 시간이 짧다 |
| 일반 방 웨이브 | 섬멸 2회, 거점·장치 3회, 기준 예산 6~7 (달팽이 위협 1.0, 멧돼지 1.6, 까마귀 1.4) | 1인 기준 방당 적 6~9마리 |
| 적 체력 | 달팽이 40, 멧돼지 55, 까마귀 45 / 망치 12 | 3~5타에 죽는다 |
| 보스 체력 | 520 (1인), 갑각 파괴 시 받는 피해 +18%씩 | 1인 DPS 약 12로 60~90초 |
| 기믹 | 전투 시작 후 12초 간격으로 1개씩, 각 12~40초 | 보스 체력이 먼저 바닥나 기믹 2~3개만 본다 |
| 기믹 실패 벌칙 | 1~2인은 `limited_damage`(제한 피해) | 실패해도 흐름이 안 바뀐다 |

### 대응안 (수치는 데이터 파일만 바꾸며, 실제 플레이로 재확인)
1. **경로를 전투 중심으로**: `regions.json` 층을 5 → 7 로 늘리고 전투 4방 + 정예 1방 + 사건/상점/휴식 각 1 을 보장한다. 정예방(체력 2배·강공격 적 1 + 호위)은 새 방 유형이다.
2. **방당 적 밀도**: 기준 예산 6 → 9, 웨이브 2 → 3, 다음 웨이브 조건 "1마리 이하" → "3마리 이하"로 겹치게 한다. 목표: 1인 방당 적 12~15마리, 4인 25~30마리. 적 체력은 유지하고 수로 늘린다(가독성 유지).
3. **방 유형 4종 채우기**: 섬멸·거점·장치 + **호위**(목재 뗏목을 강 건너로 밀며 적을 막기)를 추가한다. 기획서의 "완료 조건이 다른 일반방 4가지" 조건.
4. **보스 체력과 기믹 순서**: 보스 체력 520 → 900(1인), 갑각 파괴 없이는 받는 피해 -40%(갑각 3조각을 깨야 정상 피해). 단계 전환(65%·30%)마다 기믹을 **강제 1개** 넣고, 5개 기믹을 최소 4개는 보게 한다. 기믹 간격 12초 → 9초.
5. **기믹 실패의 무게**: 1~2인도 실패 시 `extra_adds`(추가 적 2) + 보스 체력 5% 회복. 성공 시 갑각 1조각 파괴로 보상이 눈에 보이게.
6. **기믹 복잡도**: IC-01 지지목 1개 → 2개(1인도 순서 선택), IC-02 수문 표식을 매 8초 바꿈, IC-05 잔해 제거 뒤 밧줄 고정까지 두 단계 유지. 기믹 중에도 기본 패턴 1개(집게)는 계속 나온다.
7. **목표 시간**: 1인 12~15분, 4인 15~25분. 봇 자동 플레이로 방당 시간을 측정해 `docs/verification.md` 에 기록한다.

적용 여부와 순서는 사용자 결정 후 진행한다.
